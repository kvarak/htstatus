## Functions

### Title: Training log
Status: Pending
Last updated: 2026-11-03 22:16:00

Description:
A weekly log of the user's own team's training as Hattrick reports it: training type, intensity, stamina share and trainer. Combined with the minutes the user's players played (from match lineups), it shows who was trained each week, and from the skill changes the user has seen in their own players, how many weeks each skill level took. Read only (training is never set from here), and fetched only when the user clicks "Update data".

Xml files:
Training

### Title: Players and their progress
Status: Pending
Last updated: 2026-11-03 22:14:00

Description:
The players of the user's own team(s), as Hattrick shows them to the owner: skills, form, stamina, TSI, salary, specialty, personality, loyalty, injuries, cards and goals. Each "Update data" stores a snapshot, so the user sees what changed since the previous update and how each player progressed over time. For the user's own transfer-listed players we also show asking price, highest bid and deadline. Read only (no bids are placed), and fetched only when the user clicks "Update data".

Xml files:
Players, PlayerDetails
