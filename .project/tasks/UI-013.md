# UI-013: Show progress while "Update" runs

The Hattrick update takes a while and the page just hangs, so it's easy to think it froze and click again.

**Good enough:** when the user clicks Update, disable the button and show a spinner with "Fetching data from Hattrick...". No progress bars, websockets or cancel buttons needed.

**Done when:** you can't double-click Update and it's obvious something is happening.
